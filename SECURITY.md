# Security policy

This repository contains documentation, a data file and one small script that makes read-only GET requests. It collects no telemetry and stores no secrets.

To report a vulnerability (for example in `scripts/radar.py` or the workflows), use GitHub's private vulnerability reporting for this repository ("Security" tab, "Report a vulnerability"). Please do not open a public issue for security problems.

Reports about a listed third-party tool belong to that tool's maintainers. If you believe an entry's verdict hides a security risk, open a "report stale" issue with the evidence.
